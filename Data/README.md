# Data/

Raw data are public on Gene Expression Omnibus and are not tracked in git. Only this file is tracked.

Download each series and place the sections in the folders below. The scripts read from these paths.

| Folder | GEO accession | Contents | Used in |
|---|---|---|---|
| `G4_ST2/` | GSE286413 (GSM8727283) | Visium section G4_ST2, Pai et al., 2024 | Chapters 2 and 3 |
| `G740_ST1/` | GSE286413 (GSM8727282) | Visium section G740_ST1, Pai et al., 2024 | Chapters 2 and 3 |
| `GSE253080/` | GSE253080 | 16 sections from GBM1 to GBM3, Lv et al., 2024 | Sections 2.7 and 3.6 |
| `GSE242352/` | GSE242352 (cohort B) | six sections, Webb et al., 2025 | Sections 2.7 and 3.6 |

Everything under `Results/` is created by the scripts from these files, so nothing there needs to be backed up.
